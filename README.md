# 视觉导演系统 V1.6.2

把你的想法设计成画面，再生成可用于 AI 文生图的完整提示词。

这是一个 **Agent Skill 技能包**，需要交给能够读取技能文件并遵循多步骤流程的 AI Agent 使用，例如 **Qoder、DeepSeek Harness、WorkBuddy** 等。它不是双击即可运行的绘图软件，也不会直接生成图片；最终提示词需要交给你选用的图像模型。

不同 Agent 的技能导入方式和执行能力可能不同，以上为使用入口示例，不代表已在每个平台逐一完成兼容性测试。完整本地功能还需要 Agent 能执行 Python 脚本。

## 能做什么

- 根据需求提出三套完整构思，再整理人物、场景、动作、构图、光影与材质。
- 建立可查看、可修改的视觉母版，经你确认后生成完整提示词。
- 根据人物背景和当前场合选择面部特征、妆容、发型与服装，使用裸妆、烟熏妆、低马尾等常用名称。
- 提供秦汉至民国历史发式、秦汉至现代服装参考；按需读取知识，不把整本资料塞进提示词。
- 按目标模型调整提示词表达与画幅设置方式，支持已登记的 GPT、Grok、Midjourney、Qwen Image、Krea、Z-Image 等路由。
- 在具备本地工具能力时，保存偏好、任务记录与母版，并检查名称保留、版本和复核证据。

## 怎么使用

### 1. 下载并交给 Agent

从 [最新版本](https://github.com/shaoyang0203/visual-director-system/releases/latest) 下载 `Visual-Director-System-V1.6.2.zip` 并解压。保留完整目录，包括 `SKILL.md`、`references`、`knowledge`、`scripts` 等文件，不要只复制入口文件。

如果你的 Agent 支持导入 Skill，按它的导入入口安装完整技能目录；也可以把解压目录放进 Agent 可读取的工作区，让它读取入口文件。可以直接发送：

> 请读取我提供的视觉导演系统目录中的 SKILL.md，并按其要求加载必读协议。使用这个技能帮我创作；先告诉我当前版本和可用功能，再开始讨论需求。

请把目录位置告诉 Agent，或通过它的文件选择功能提供目录。如果 Agent 不能访问本地文件，需要先使用该平台支持的上传或技能导入方式。

### 2. 说明想画什么

告诉 Agent 题材、人物、场景、目标图像模型，以及必须保留的要求。例如：

> 我想设计一位女大学生在校园图书馆窗边读书的画面，用于 Qwen Image 2.1。保留黑色长发和低马尾，妆容自然，请先给我三套构思。

不知道怎么用时，直接说“说明”，让 Agent 展示使用说明书。

### 3. 选择方案、确认母版

流程是：**提出需求 → 查看三套构思 → 选择方向 → 查看完整视觉母版 → 修改或确认 → 获得完整提示词**。

选中方案不等于确认母版。请检查母版中的人物、妆发、服装和画面设计，确认具体版本后再让 Agent 编译。之后需要修改，可以直接说“保留其他内容，把妆容改为烟熏妆”等明确要求。

### 4. 将提示词用于图像模型

复制最终提示词到对应图像平台；如果画幅要求列在提示词外，请在该平台界面或工作流中设置。这个技能负责设计和提示词生成，图片由目标图像模型生成。

### 可选：偏好与本地记录

希望跨会话保存偏好、存档与任务记录时，让 Agent 配置 Python 环境和一个固定的、位于技能目录之外的数据目录。具体操作见 [本地工具说明](references/local-tools.md) 与 [Python 环境要求](docs/python-environment.md)。

没有 Python 时仍可按协议进行对话创作，但不能使用本地保存和程序检查；Agent 应如实说明当前模式。技能自带脚本不调用图像服务，所用 Agent 的联网及数据处理方式由其平台决定。
