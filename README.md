# 视觉导演系统 V1.7 Lite

把你的想法设计成画面，再编译成目标 AI 文生图模型可用的紧凑提示词。

这是一个 **Agent Skill 技能包**（内部语义版本 `1.7.0`，技能名 `visual-director-system-v1-7-0-lite`），需要交给能够读取技能文件并按流程协作的 AI Agent 宿主使用，例如 **Qoder、DeepSeek Harness、WorkBuddy** 等。它不是双击运行的绘图软件，也不会直接生成或编辑图片；最终提示词需要交给你选用的图像模型。

不同 Agent 宿主的技能导入方式、上下文管理与工具能力各不相同，以上仅为使用入口示例，不代表已在每个平台逐一完成兼容性测试。`Lite` 指常驻核心协议轻量化、其余模块按需加载与默认直接交付，不代表未经验证的运行速度提升或调用费用承诺。

## 能做什么

- **默认直接交付**：需求明确时同轮完成画面设计与紧凑提示词，旁边只列影响你选择的重要补充与歧义；需要探索时再按需求给出方向选项，需要逐项把关时说“严格模式”先看九维设计再编译。
- **按需轻量化加载**：每次仅常驻入口与核心协议（`SKILL.md` + `references/core.md`），创作方法、人物造型、11 张目标模型路由小卡与 272 条离线知识均按需读取，不把整本资料塞进上下文或提示词。
- **已有提示词保真整理**：保持原细节粒度，合并跨处重复、消除歧义，原文未写的设计与项目默认不擅自添加。
- **人物与历史服饰参考**：支持面部特征、20 条妆容、20 条现代发型、秦汉至民国历史发式、秦汉至现代服装选型，并在提示词中保留已选定的具体造型名称。
- **多模型交付路由**：按目标模型调整提示词结构与画幅传递方式，支持通用自然语言、GPT、Grok、Midjourney、Qwen Image、Krea、Z-Image、MOSS Image / Layout 等 11 条已登记路由。
- **可选本地工具（需 Python）**：在宿主具备本地脚本执行能力且你明确需要时，保存偏好模板、存档与任务快照，并对版本、结构、比例、画面文字和名称证据做确定性校验。

## 安装与使用方法

### 1. 下载并交给 Agent

从 [最新版本 Release](https://github.com/shaoyang0203/visual-director-system/releases/latest) 下载 `Visual-Director-System-V1.7.0-Lite.zip` 并解压。请保留完整目录结构（含 `SKILL.md`、`references`、`knowledge`、`adapters`、`schemas`、`scripts` 等），不要只复制单个文件。

- 若你的 Agent 支持导入 Skill，通过其技能管理入口导入解压后的完整目录；
- 也可将解压目录放入 Agent 可读取的工作区，直接发送：

> 请读取视觉导演系统目录中的 `SKILL.md`，并按其中的读取表加载核心协议，使用这个技能帮我设计提示词。

### 2. 直接说想画什么

告诉 Agent 题材、人物、场景、目标图像模型以及必须保留的约束即可。例如：

> 设计一位女大学生在校园图书馆窗边看书的画面，用于 Qwen Image 2.1。保留黑色长发和低马尾，裸妆。

想了解全部指令与功能时，直接对 Agent 说“说明”。

### 3. 按需探索或局部修改

- 想先看不同构思：说“给我几个方向”；
- 想先确认完整九维设计：说“严格模式”；
- 想整理现成提示词：说“保留原有设计，整理得紧凑一些”；
- 想局部调整：直接说“其他保留，把妆容改为烟熏妆”。

### 4. 复制到图像模型生图

复制最终提示词到目标图像平台生成图片；若画幅要求列在提示词块外，请在该平台界面或工作流参数中设置对应比例。

### 可选：偏好模板与本地记录

希望跨会话保存偏好模板、存档或启用严格任务快照校验时，可让 Agent 配置 Python 环境并在**技能目录之外**指定固定的数据目录。详见 [本地工具说明](references/tools.md) 与 [Python 环境要求](docs/python-environment.md)。没有 Python 时照常进行对话创作，仅不可使用本地保存与程序校验。

## 能力边界与兼容说明

- **关于轻量化与效果边界**：本版大幅缩减了常驻协议体积并重写了正向表达示例，但协议字符数下降不等同于实际运行速度提升或费用下降；不声称不同宿主的创作简练度问题已彻底解决，也不声称已完成真实出图效果验证。
- **关于知识与名称校验**：历史发式与服装条目用于创作选型参考，精确史实复原仍需另核专业史料。本地工具的名称检查覆盖已登记中英文名称组，未登记译名、人物归属与语义等义仍依赖宿主复核。
- **版本兼容性限制**：
  1. 整理任务（`limited`）在原文未指定媒介或画幅时使用 `Schema 0.3.1` 空值母版快照，旧版 `V1.6.3` 及更早工具无法读取该格式；
  2. `prefs.py archive add` 仍执行完整必填校验，不支持直接归档媒介或画幅为 `null` 的 `0.3.1` 整理母版（拒绝时会返回明确错误，不损坏已有偏好数据）。
