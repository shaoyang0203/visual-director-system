# 视觉导演系统 V1.8-Flash

把你的想法变成一个站得住的画面，再写成目标 AI 文生图模型可用的提示词。

这是一个**纯文本、零脚本的 Agent Skill 技能包**（版本 `V1.8-Flash`，技能名 `visual-director-system-v1-8-flash`）。交给能读取本地技能文件的 AI Agent 宿主使用，例如 Codex、Claude Code、Antigravity、Cursor、Qoder、DeepSeek Harness、WorkBuddy 等。它不生成或编辑图片，提示词交给你选用的图像模型出图。

> 本 SKILL 开发累计消耗 22 亿 token。

## 更新日志

### V1.8-Flash（最新版）

**整套设计系统重新设计。** 这一版不是在旧版上删减或修补，而是从“怎样把一个想法变成一张站得住的画面”出发，重写了系统理解需求、构思画面、调度、查知识、修改和交付的方式。只有知识库的专业内容和 11 个交付目标沿用。

和以前的版本相比，主要区别：

|方面|以前的版本|V1.8-Flash|
|---|---|---|
|设计怎么推进|按人物、场景、摄影、光影、材质等多个专业领域分别考虑，再按九个区域组织设计|以场面调度为核心：先定此刻、站位、机位、光源四个决定，影子、反光、材质和取景顺着这些决定推出来|
|你的要求怎么保护|分散在许多条“不要擅改、不要漏写、不要泛化”的规则里|区分“你说的”“系统替你定的”“由此推出来的”三类：你说的不动，系统定的可以调，推出来的跟着变|
|交互节奏|常见流程是先给几套构思，选定后展示完整设计，确认后再写提示词|默认一轮直接给出提示词，只把影响你选择的决定告诉你；想看方向时会给几句不同的画面构想|
|整理已有提示词|和创作共用一套规则，容易被补上原文没有的设计|整理时把原文全部当作你的要求，不补设计；遇到歧义会问你或说明|
|修改|修改后通常要重新展示完整设计并确认|只改你点名的部分，连带调整真正受影响的光影、遮挡和材质，并告诉你改了什么|
|读取负担|每次要先读多份协议|日常只读一份文件，写成品时再读一张交付格式表，知识库按需查|

## 它怎么工作

- **场面调度**：先决定此刻、站位、机位、光源，让影子、反光、材质和可见范围顺着这些决定成立；写成品前核对你的要求、数量与归属、可见性和画面关系。
- **你说的原样保留**：你明确给出的人物、服装、动作、机位、画幅、光线和画面文字都会保留，不会被“更好看”替换掉；系统替你做的关键决定会告诉你，方便直接改。
- **一套机制，多种任务**：从零创作、给方向、局部修改、整理已有提示词、翻译和换模型格式。整理时只合并重复、消除歧义、换格式，不添加原文没有的设计。
- **知识库按需点读**：272 条专业视觉与历代妆发服饰知识，只在选名字或拿不准后果时读命中的那一段。
- **11 个交付目标**：generic、GPT、Midjourney、Krea 2、Grok、Qwen Image 2.1、Z-Image、Gemini、Seedream、MOSS Image、MOSS Image Layout。

## 上手

1. 从 [GitHub Releases](https://github.com/shaoyang0203/visual-director-system/releases) 下载 `Visual-Director-System-V1.8-Flash.zip`，完整解压，保留目录结构。
2. 通过 Agent 的 Skill 导入入口添加该目录，或把目录放进工作区后说：
   > 请读取视觉导演系统目录中的 `SKILL.md`，用这个技能帮我设计提示词。
3. 说出想法，例如：
   - “雨夜，古风女侠在客栈门口等人，用 mj。”
   - “给我几个方向：校园图书馆窗边看书的女孩。”
   - “其他不变，改成清晨，雨停了。”
   - “帮我把这段提示词整理紧凑，保持原有设计。”
   - “说明”
4. 把代码块里的提示词复制到图像模型；代码块上方若写了画幅，请在平台或工作流里设置。

## 边界

- 纯文本，不含任何脚本或程序校验；名称保真与格式由宿主模型按规则自查。
- 本次对话内的要求一直遵守，不跨会话保存。
- `Flash` 指纯文本、零脚本和默认一轮交付的形态，不代表出图速度或费用承诺；未做跨宿主实测与真实出图验证。
- 需要本地脚本、跨会话偏好模板或程序门禁的用户，可选同系列 `V1.7 Lite`。
