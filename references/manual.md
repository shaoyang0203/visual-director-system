# 视觉导演 V1.9-Flash-Turbo 使用说明

平时直接说你想画什么，一轮就能拿到干净可用的生图提示词。

## 常用说法速览

1. **直接出词**
   - 画面已想好：`雨天，中国美女穿黑外套站在海滩面对大海，侧后方拍摄，回头看镜头流泪，风吹起湿发`
   - 只给感觉：`想要一个人在大城市深夜里的孤独感` / `画一张纯靠色彩和构图震撼的沙漠画面，不要故事`
   - 想先挑点子：`我想画雪夜酒馆，先给我三个不同方向挑挑`
2. **局部修改与换画幅**
   - `其他不变，改成黄昏暖阳`
   - `把画幅改成 16:9 横屏`（系统会同步重排人物与景物的左右摆位，不只是改比例数字）
3. **参考图反推与当轮借元素（需宿主支持看图）**
   - 整图忠实反推：`帮我把这张参考图反推成提示词`
   - 当轮借元素画新图：`用参考图里这件外套和配色，画她在清晨卧室窗边喝热茶`
4. **已有提示词整理与指定生图平台**
   - 精简整理：`帮我把这段提示词精简去重，保持原意`
   - 指定平台：句末直接带平台名即可，如 `krea2`、`midjourney`、`grok`、`gpt`、`qwen-image`、`即梦`。

## 边界说明

- 本次对话内提出的要求（如“接下来都用 16:9”）在本场对话内持续有效；本版为轻量直出形态，不含跨会话偏好保存与本地模板存档功能。
