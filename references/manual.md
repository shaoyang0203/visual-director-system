# 视觉导演系统说明书（V1.7 Lite · 1.7.0）

本说明书只在用户要求时展示，不参与创作流程。想看哪一节直接说，例如“说明书：偏好怎么用”。

---

## 模块 1｜它是什么

把想法设计成画面，再把画面编译成目标图像模型可用的紧凑提示词。

- 它做：理解需求 → 设计画面 → 给提示词；需要时先给方向选项，修改时局部改版。
- 它不做：不自动出图、不调用图像模型、不修改你的照片、不修改设计规则本身。
- 设计质量由宿主语言模型承担；本地程序只做校验、记录和排版，不能证明画面好看。

## 模块 2｜一次创作怎么走

1. **说需求**。给主题即可；也可以指定人物、场景、光色、画幅、目标模型。
2. **拿提示词**。需求明确时直接给成品；成品旁只列会影响你选择的内容：系统补充的重要设计（尤其妆发、服装名称）、对歧义的理解、需要你决定的点。
3. **想先看方向**就说“给我几个方向”；需求本身有几个同样合理的方向时，系统也会先问。数量按需求定。
4. **要改**就直接说，例如“其他保留，把妆容改为烟熏妆”。只改你点名的部分，复查受影响的关系后给新提示词。
5. **要看完整设计**就说“完整设计”或“严格模式”：先按九个维度展示设计，确认后再编译。
6. **已有提示词**可以说“保留原设计，整理得紧凑一些”：保持原细节粒度，合并重复、消除歧义，原文没有的设计不添加。

## 模块 3｜九个设计维度

创作意图与约束、创意方向与瞬间、视觉主体与层级、人物美术、场景美术、动作与空间关系、摄影与构图、光影与色彩、材质与视觉表现。平时是系统检查漏项的清单；你要求完整设计、严格模式，或进入本地工具任务流程时，会按九区域展开。

## 模块 4｜画幅

没有统一默认比例。你指定了就用你的；没指定时按主体朝向、景别、动作方向、横纵空间、前景与留白决定。改比例后会复核人物尺度、裁切、前景、背景和留白，不只换参数。目标模型不支持该比例时，会说明并请你选择。

## 模块 5｜知识库

272 条（总导演 15、摄影 23、人物 184、场景 10、光影 28、材质 12），110 项来源，离线可查，按需读取。
人物包括面部、20条妆容、20条发型、秦汉至民国历史发式、秦汉至现代服装。你可以指定具体造型，也可以交给系统按当前活动补充。无妆与裸妆不同；已设定的发长发色换场景不会擅改；时代与身份是线索，允许跨时代借鉴。目录见[妆容与发型](../knowledge/nav-makeup-hair.md)、[历史发式](../knowledge/nav-historical-hair.md)、[服装](../knowledge/nav-clothing.md)。
系统选定的妆容、发型、服装名称会写进提示词，不会被压缩成“妆容自然”一类泛称；你要求的部位被取景挡住时，系统会先调整取景，或问你取哪一个。

## 模块 6｜模板：偏好怎么记

**模板是偏好的唯一形式**，没有“单条偏好”这种东西——单条就是只含一项的模板。

| 概念 | 说明 |
|---|---|
| 维度 | 主体 / 光影 / 配色 / 镜头 / 材质。不同维度可同时生效，同维度只能有一个默认。 |
| 模板默认关闭 | 新建模板一律不生效，必须你明确“设为默认”才自动应用。 |
| 三种作用 | `默认填充`（没说就填）/ `倾向`（同类场景偏向用）/ `避开`（设计时排除） |
| 作用域 | 场景 + 模型。模型经验只挂在该模型上，换模型不跟着走。 |

例子：你说“性感 = 胸大、腰细、屁股大、黑丝，设为默认”。系统建一个名为“性感”的主体模板，属性写的是可见描述；此后你没提身材时，女性主体按这套填充；你若说“这次清瘦一点”，本轮以你为准。

**模板名可以抽象，属性必须看得见。** “高级感”能当模板名，但属性得写成具体的光比、材质、色彩关系，否则程序拒绝。

## 模块 7｜存档：只记录，不影响设计

当你对某条产出的**整体**表示满意（“这张真好”），系统把**母版快照 + 提示词原文**一起存下来，不生成模板、不影响以后的设计。

存档的用途只有一个：以后你要求“看看我存的那些，总结我偏好什么”时，作为推断依据。

## 模块 8｜推断：只能由你发起

- 系统**不会**在你创作时偷偷总结你的偏好。
- 只有你说“帮我从已保存的提示词里推断偏好”，才会读取存档、产出候选模板。
- 候选一律是**待确认**状态，不参与设计；你逐条点头后才生效。
- 推断读的是母版里的设计方向，不是提示词里的措辞。

## 模块 9｜三个开关与提醒

| 开关 | 作用 |
|---|---|
| `record` | 关掉后不再记录任何东西 |
| `apply` | 关掉后仍可查询，但设计时不用模板 |
| `remind` | 关掉后回答末尾不再提示 |

默认每轮回答末尾有一行 `[模板生效：xxx｜yyy]`，告诉你这次用了哪些模板；没有生效模板就不显示。

## 模块 10｜命令清单

所有命令都要先给数据目录（必须**在技能目录之外**、跨会话不变）：

```powershell
$py = '<你的 Python 解释器绝对路径>'
$d  = 'D:\pa-data'                      # 你的数据目录
$s  = '<技能目录>\scripts'

& $py -B -X utf8 "$s\prefs.py" --data-dir $d init
& $py -B -X utf8 "$s\prefs.py" --data-dir $d status
& $py -B -X utf8 "$s\prefs.py" --data-dir $d template list
& $py -B -X utf8 "$s\prefs.py" --data-dir $d template add --input t.json
& $py -B -X utf8 "$s\prefs.py" --data-dir $d template on --id T0002
& $py -B -X utf8 "$s\prefs.py" --data-dir $d template off --id T0002
& $py -B -X utf8 "$s\prefs.py" --data-dir $d template stop --id T0002 --reason '不再喜欢'
& $py -B -X utf8 "$s\prefs.py" --data-dir $d query --scene 室内 --model z-image
& $py -B -X utf8 "$s\prefs.py" --data-dir $d archive add --input a.json
& $py -B -X utf8 "$s\prefs.py" --data-dir $d infer --input i.json
& $py -B -X utf8 "$s\prefs.py" --data-dir $d set --key remind --value off
```

创作流程本身另有 `pa15.py`（任务快照、母版展示、确认、编译、交付）：

```powershell
& $py -B -X utf8 "$s\pa15.py" --data-dir $d --task t1 new --request '...'
& $py -B -X utf8 "$s\pa15.py" --data-dir $d --task t1 show
& $py -B -X utf8 "$s\pa15.py" --data-dir $d --help
```

知识库：

```powershell
& $py -B -X utf8 "$s\knowledge.py" search '雨夜 湿地' --limit 3
& $py -B -X utf8 "$s\knowledge.py" show LC-15 MA-05
& $py -B -X utf8 "$s\knowledge.py" audit
```

**没有 Python 时**：创作照常进行，但模板、存档、任务记录全部不可用。系统必须明说“本地记录不可用”，不得声称已保存。

## 模块 11｜边界与限制

- 不自动出图；不验证图像质量。`Lite` 指核心协议轻量化常驻与默认直接交付，协议字符缩减不等同于运行速度提升或费用下降，不保证所有宿主创作简练度一致。
- 文本路径（默认）：设计与成品同轮给出；“严格模式”可改为先确认后编译。
- 工具路径（你要求任务记录、严格存档或程序校验时；有 Python 不会自动进入）：程序检查结构、状态、哈希、比例、画面文字逐字和名称组（`matched`/`missing`/`not_checked`）；同轮给出的提示词只是预览，必须由你的确认消息批准当前版本后才走提交与交付。
- 兼容限制：整理任务（`limited`）在原文未指定媒介或画幅时使用的 `0.3.1` 空值母版快照，旧版 `V1.6.3` 及更早工具无法读取；`prefs.py archive add` 仍执行完整必填校验，不支持直接归档 `0.3.1` 空值整理母版。
- 模板只作用于“设计输入”和“编译语言”，不改核心流程、知识库、母版结构、编译检查。
- 语言：按模型路由默认。你的长期语言偏好会覆盖路由默认语言，包括 Qwen 的英文默认，但结构不变——Qwen 仍是单段观察式描述。
- 模型经验不区版本：模型升级后旧经验可能失效，需要你观察并停用。
- 数据目录在技能目录内会被拒绝写入；Sandbox 只允许写工作区的宿主，必须把数据目录放在工作区内。

## 模块 12｜常见问题

**我设的紫发没生效？**
先看 `template list`：模板默认关闭，需要 `template on --id` 设为默认；或者你这次明确指定了别的发色，本轮以你为准。

**为什么一直有那行方括号提示？**
是提醒，不是错误。`set --key remind --value off` 可关。

**我说“这张真好”，为什么没记住我的偏好？**
整体赞赏只进存档，不生成模板——避免把一次巧合当成长期审美。想要偏好，明确说“以后都这样”。

**为什么系统没自己总结我的喜好？**
按设计，它不会。你说“帮我推断偏好”才会。

**换了模型，之前的经验还在吗？**
带模型作用域的模板只在那个模型下生效；全局模板不受影响。

上面的列表为常用示例。完整命令及每条参数以 `prefs.py --help`、`prefs.py template --help` 和相应子命令 `--help` 为准；模板还有 `template show --id <ID>`、`template resume --id <ID>`，列表支持 `--dimension`。pending 推断不能由resume确认，须用户明确同意后用on。
