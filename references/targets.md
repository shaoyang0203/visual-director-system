# 目标平台交付格式（按需读取）

仅在用户点名具体生图平台或模型时读取本表。切换平台时画面可见事实保持不变，只调整语言与画幅承载位置；默认只输出代码块与必要外部设置，不附版本对比说明。

| 平台 / 常用别名 | 默认语言 | 画幅承载位置 | 格式要点 |
|---|---|---|---|
| `generic`（默认通用） | 中文 | 代码块上方一行 | 自然语言画面描述，不带平台专属参数 |
| `krea2` / `krea` | 中文 | 代码块上方（工作流外部设置，不写像素尺寸） | 自然语言描述；画内文字加引号 |
| `midjourney` / `mj` | 简洁中文或英文 | 代码块内最末尾 `--ar W:H` | `--ar` 后不再写正文；仅在用户指定时加 `--raw`、`--s`、`--v` |
| `grok-web` / `grok` | 中文 | 代码块上方（限网页端可选 `2:3、3:2、1:1、9:16、16:9`） | 开头明确一次媒介（如 `写实摄影。`），主体与动作先行 |
| `gpt-web` / `gpt` / `chatgpt` | 中文 | 代码块内末尾 `Aspect ratio: W:H.` | 连贯自然语言描述 |
| `qwen-image-2.1` / `qwen-image` | 英文 | 代码块上方（外部宽高设置，正文不写比例） | 单段第三人称现在时观察描述；不输出改写器 JSON |
| `seedream` / `即梦` | 中文 | 代码块内末尾一句自然语言画幅 | 主体与动态先行，画内文字加双引号 |
| `z-image` / `moss-image` | 中文 | 代码块上方（外部工作流宽高设置） | 连贯自然语言描述；采样参数仅在用户索要时提供 |
| `gemini-image` / `nano-banana` | 中文 | 代码块内末尾一句自然语言画幅 | 画内文字加引号并点明可见位置 |

未列入上表的模型：按通用中文自然语言交付，并在代码块上方简短注明画幅在所用工具中设置。
