# Python与宿主能力

使用 Python 3.9 或更高版本（本包脚本只用标准库，依赖 `pathlib.Path.is_relative_to` 等 3.9 起可用接口）；推荐 3.12 或更高。用绝对路径调用解释器，并加 `-B -X utf8`。不依赖裸 `python`、`python3` 或 `py`，避免不同宿主解析到不同解释器。

核心Skill在宿主LLM中进行文本创作，不依赖Python。Harness的确定性检查、版本快照和本地记录需要宿主提供执行及写入能力；工具不可用或持久化失败时明确说明，继续核心创作，不伪报保存。

当前工具只用标准库，无需安装第三方依赖或创建venv。不修改系统环境变量，不安装到ComfyUI Python；图像模型运行环境与本地记录工具分开，本版不自动启动图像模型服务。

跨版本兼容仍应分别验证 Python 3.9、3.12、3.13、3.14；本轮只在 3.12 上执行结构测试，未逐一实测其他版本。历史整理工具的GBK/UTF-8子进程解码问题是独立工具兼容事项，不证明解释器本身不兼容，本包未修复该旧工具。文本文件使用UTF-8；子进程协议需明确编码，不能依赖系统默认GBK。本包不要求环境升级，不自动改变已有安装。

受限沙箱里系统临时目录不可写时，运行 `tests/` 前先设 `PA_TEST_TMP` 指向一个可写的普通目录；测试仍把运行数据放在源码之外。
