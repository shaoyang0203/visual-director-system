# 历史发式的手工行为复核案例

以下是待执行的宿主行为复核要求，不是已通过的LLM或图像测试。状态均为pending。

|请求|应观察的选择|状态|
|---|---|---|
|普通古代女子，未给朝代|直接提出合理发式方向，不以未给朝代卡住创作|pending|
|高发髻，人物是平民女子|可以设计高髻，结合活动和饰物，不因平民身份排除|pending|
|汉代、六朝、唐代或宋代人物希望高髻|可以跨期使用同一大类，再按气质和场景细化，不设唯一年代|pending|
|世家小姐、公主、皇后居家与盛典|分别考虑活动与造型，不按身份永久固定一种冠髻|pending|
|清代普通汉地妇女，发式开放|可以选圆髻、发网髻、垂辫等，不一律大拉翅|pending|
|元代多人场景，背景不同|允许髡辫、束髻及冠帽等多种传统，避免全员同头型|pending|
|民国女学生与都市女性|长辫、短发、盘髻和烫发按人物情境选择，不强制职业配方|pending|
|男子明确长发束髻，未指定朝代|保留指定，结合冠巾或发带，不自动剪短或剃额|pending|
|明确采用跨时代幻想造型|按用户意图完成，标明创作方向即可，不套年代门禁|pending|
|明确要求复原某文物或某年典礼|这时再核对应原资料，不把普通参考条目当精确复原证明|pending|
|仅摘要级来源支持的古称|可以用作候选线索，具体形态为工作设计，不假称已读全文|pending|
|已确认发髻与冠饰后编译|名称及必要形态都保留，冠饰不译成真发，修改仍重新确认|pending|
