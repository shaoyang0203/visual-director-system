# V1.6.3 人物设计复核案例

以下为交付后的手工行为验收要求，未执行真实宿主或图像模型测试，不是历史通过记录。使用时给宿主完整技能与单个请求，检查实际构思、母版、确认及最终成品；不用宿主自报“已遵守”代替观察。状态初始均为pending。

|案例|请求/情境|应观察的决定|状态|
|---|---|---|---|
|A01|清纯女大学生在校园日常|可选无妆/裸妆并区分；按当前场合设计发型，不仅写“清纯漂亮”|pending|
|A02|同一人物改为夜店聚会，妆发开放|主动重选夜间造型，同时保留清纯气质、面部、发长发色；不固定浓黑或擅加暴露服装|pending|
|A03|明确无妆、黑长直的人物在夜店|无妆与黑长直优先，不以场合替换成裸妆、烟熏或卷发|pending|
|A04|明确长脸、圆润鼻尖、平缓眉形|保留组合，不套长脸必配某鼻某眉；当前机位下协调可见面|pending|
|A05|学生参加晚会、舞者在休息|按当前活动而非职业永久选妆；使用常用名称，不生成职业妆标签|pending|
|A06|同一人物的特写与远景/背影|近景可细化妆面，远景取舍轮廓色块，背影不声称看清眼线鼻形|pending|
|A07|更换发型会遮住指定耳饰|先提协调方案，保留指定可见性；触及已定设计按原流程授权改版|pending|
|A08|雨中或舞蹈情境|仅据实际暴露和活动添加状态，不固定晕妆、汗水或所有头发同时飘动|pending|
|A09|用户只说烟熏妆|可保留名称，必要时提出本图版本；不把所有变体/步骤自动写进母版|pending|
|A10|已确认棕色烟熏、哑光唇、低马尾后编译|术语与具体限定均覆盖，不用精简或模型能力为由删掉；修改形成新版本并重新确认|pending|
|A11|真实历史人物与新中式风格请求|区分史实考据与当代创作标签，未考据不冒称年代准确|pending|
|A12|只做纯翻译或保真模型迁移|不重选鼻型、妆容、发型，不强加新设计或三方案|pending|

## 图像表达的后续小型对照

在用户另行指定目标模型、版本、界面/工作流与成本后，比较名称、纯拆解、名称+关键特征三种表达；保持其余场景与参数一致。支持种子时在多组种子上配对，每种多张；不能固定种子时记录随机条件。记录平台改写的提示词（若可见），不能把不同平台改写造成的差异归为术语效果。

分别观察风格识别、用户具体限定、人物面部自然度、发型结构与其他要求保留；不能只挑最好看的一张。纯拆解与名称的细节若不等价，标明比较的是表达方案，不能声称同义措辞对照。结果仅适用于实测条件，不外推所有模型。原始图像、Prompt、参数和评价保存到发行目录之外。
