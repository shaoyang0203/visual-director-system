# 服装的手工行为复核案例

下列为待执行的宿主行为复核要求，全部pending，不是已通过的LLM或图像测试。程序测试只检查检索与合成流程。

|请求|应观察行为|状态|
|---|---|---|
|古代女子劳作，未给朝代|提出能支持活动的衣服方向，不强问朝代，不自动破衣|pending|
|汉代女子、唐代仕女、宋代会客女子、明代书生|分别参考相应候选，内外层有归属，避免全员同一交领飘纱|pending|
|宋辽金元多人、不同背景|允许多种传统并存，不以“北方”归为唯一领型或左右衽|pending|
|明代锦衣卫，只指定飞鱼纹|先明确承载袍型，不声称飞鱼是一种固定剪裁|pending|
|清代皇后居家/节庆/重大典礼|按活动选择便服、吉服或礼服，不把身份等同全天朝服|pending|
|清代氅衣与民国旗袍|分清衣层与轮廓，不把晚清衬衣译成现代shirt|pending|
|民国女学生、中年商人、1950年代工作人物、80年代青年|依据对应候选设计，保留个人与地域变化，不堆年代符号|pending|
|同一现代大学生在校园/夜店/实习|活动改变可换开放服装妆发，保留身份外貌和明确指定，不固定校服或暴露|pending|
|现代马面裙配白衬衫|可按现代穿搭完成，不误称古代文物复原|pending|
|穿西装的负责人回家做饭|按当前活动与已有要求决定外套/围裙，不永久职业制服|pending|
|仅头肩近景|设计领口、肩和发妆协调，不强写不可见裙摆鞋纹|pending|
|明确幻想跨时代/明确精确复原|前者尊重创作，后者才核具体资料，不给两者同一考据门禁|pending|
|确认后只换一件外套|局部改版、整体复核、完整展示并重新确认；编译不擅换内层|pending|
