# 面部与妆发的设计基础

按问题读取，不是每张图必填清单。P为来源所支持的方法，具体人物组合和场景选择为C；所有图像模型执行均为M、未测试。

## CH-13 面部轮廓与比例关系
<a id="ch-13"></a>

检索词：脸型,长脸,圆脸,方脸,鹅蛋脸,颧骨,下颌,face shape
关联：CH-04,CA-03,CH-14
来源：S53
证据：P,C,M

**定义与依据**：观察脸的长宽、额颧颌宽度及下巴收束，先保留用户指定的整体轮廓。画师资料支持从大形与比例组织五官；具体人物组合是本库C级创作选择，不是测量或相面结论。

**设计与谨慎**：近景挑选一两个关键轮廓特征；长脸可以保留纵向感，也可以通过造型组织改变观感，先看创作意图。鼻型、眉形没有唯一配对，不以统一小脸替代角色。机位与透视也会改变所见比例，不能把镜头效果当骨相。

**文字例（C/M，非固定模板）**：略长的椭圆脸，下颌柔和收束。


## CH-14 眉眼鼻唇与人物辨识
<a id="ch-14"></a>

检索词：五官,眉形,眼型,鼻型,唇形,眉毛,鼻梁,facial features
关联：CH-13,CH-15,CH-18
来源：S53
证据：P,C,M

**定义与依据**：五官需要在同一张脸上组织形态、间距与主次。资料仅支持观察比例和位置的绘画方法，具体鼻眉组合与角色表达为C级设计；社会地位不由五官决定。

**设计与谨慎**：需要时选择眉毛浓淡/走向、眼型与外眼角、鼻梁与鼻尖轮廓、唇峰与厚薄的关键特征。不固定填满全部部位，不以部位堆词代替整体；自然眉形与修饰后眉形、眼型与眼线、唇形与唇色分清。参考人物已有特征优先。

**文字例（C/M，非固定模板）**：眉形平缓，鼻梁线条清晰，鼻尖圆润。


## CH-15 肤质与妆面质感
<a id="ch-15"></a>

检索词：肤质,皮肤,哑光,水光,珠光,毛孔,汗光,skin texture
关联：CH-05,MA-06,LC-08
来源：S47,S46
证据：P,C,M

**定义与依据**：妆面明暗、颜色和反光可分别设计；品牌资料提供局部妆面表现示例，不证明任一肤色都应使用同种底妆。肤色、毛孔与年龄纹理沿用角色设定。

**设计与谨慎**：根据景别选哑光、润泽或局部珠光，不一律整脸发光。区分底妆光泽、皮肤油脂、运动汗光及湿水，交光影/材质协调；无妆也有自然反光。远景不用毛孔描述抢占重点，不为精致自动美白磨皮。

**文字例（C/M，非固定模板）**：底妆呈柔和哑光，颧骨顶部保留少量光泽。


## CH-16 按人物与当前情境选妆发
<a id="ch-16"></a>

检索词：情境,场合,校园,女大学生,夜店,酒吧,舞者,妆造,角色背景
关联：CH-06,CH-17,CH-18
来源：S44,S47,S15
证据：P,C,M

**定义与依据**：资料展示柔和烟熏可用于晚间社交、角色造型需协作；具体身份与场景到妆发的映射是C级建议，没有职业唯一配方。先服从用户要求、有效偏好与人物已有特征，再补开放项。

**设计与谨慎**：清纯女大学生校园日常可选无妆/裸妆；同一人物去夜店聚会时主动重选适合当前场合的妆发，可考虑柔和烟熏或Soft Glam，不把校园无妆一直继承，也不固定浓黑。明确无妆仍优先。舞者的演出与休息可不同；身份不推出地点、服装暴露程度或性格。

**文字例（C/M，非固定模板）**：保留清纯气质与黑色长发，采用柔和棕色烟熏眼妆。


## CH-17 妆发状态与跨领域协调
<a id="ch-17"></a>

检索词：状态,湿发,汗水,脱妆,碎发,遮挡,耳饰,刘海,发饰
关联：CH-04,CH-10,SC-03,MA-06
来源：S54,S55
证据：P,C,M

**定义与依据**：梳理、束发与发饰存在固定和自由部分；资料仅提供具体发型结构示例。活动/天气到可见状态的变化是C级判断，不是材料测试或必然结果。

**设计与谨慎**：有依据才加入湿发贴附、碎发散落、局部汗光或妆面变化；不见雨就固定晕妆。检查头饰支撑、发髻与领口、耳饰可见性、刘海投影、面部角度和动作。更换场景可重做梳理，不能未经允许改变已定发长、发色、卷直约束或五官。

**文字例（C/M，非固定模板）**：低马尾保持束紧，额前少量碎发因动作散落。


## CH-18 风格名称与必要特征的表达粒度
<a id="ch-18"></a>

检索词：提示词,专业术语,风格名称,细节,妆容名称,发型名称,表达粒度
关联：CH-14,CH-16,DR-04
来源：S44,S45
证据：P,C,M

**定义与依据**：资料能支持术语的可见特点，不能证明任何图像模型认识名称或越详细越好。名称、纯拆解、名称加特征都是待目标模型实际验证的表达假设。

**设计与谨慎**：先选定设计，再用名称或名称加少量必要限定表达；不把适用场景、所有可选配色、化妆步骤或知识段落塞入母版。广义风格需要本图的具体化。不得静默删除已确认限定；若发现过细需删改，先新母版确认。按原目标Adapter等义转换，不新增路由或负向词。

**文字例（C/M，非固定模板）**：棕色烟熏眼妆，边缘柔和晕染。
