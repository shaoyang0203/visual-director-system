# 秦汉至民国发式：宽松的背景关联

本专题服务视觉创作。代表时代、常见人物形象和场合是选择线索，不是“只有某朝某阶层能用”的配对表。用户明确造型优先，普通古风不增加考据问答或年代门禁；只有用户明确要求某文物、某年典礼或严格复原时，才核对其特定细节。发式、冠帽、发罩、头饰和制作方式分列，允许组合但不冒充同一种头发。
## CH-59 按发式关联时代与人物
<a id="ch-59"></a>

检索词：历史发型,历史发式,时代关联,秦汉,民国,跨时代,高发髻
关联：CH-16,CH-60,CH-61,CH-62
来源：S62,S64,S79
证据：P,C,M

**选择方法**：先用轮廓（高/低、环/盘、披/束、辫/剪）找候选，再参考时代、人物背景与当前活动。高髻可关联汉、六朝、隋唐至宋，也出现在侍女和舞者形象；宫廷/贵妇关联不等于专用。明示平民不自动排除盛装，高地位不自动加最高髻。

**使用方式**：用户只说“古代女子”时，可给有方向的古典造型，不强问朝代；指定唐代或民国时优先选有相应代表性的候选，不承诺历史唯一解。

## CH-60 秦汉至民国的时期导航
<a id="ch-60"></a>

检索词：时期导航,秦汉,魏晋南北朝,隋唐五代,宋辽金元,明清,民国
关联：CH-59,CH-61,CH-62
来源：S71,S75,S76,S79
证据：P,C,M

**覆盖**：秦汉、魏晋南北朝、隋唐五代、宋辽金元、明、清、民国均列入口，男女都有候选。秦汉不把秦俑男子偏髻扩成所有秦汉女子标准；宋辽金元并存多种传统；清代汉地妇女与旗人造型分开参考；民国的髻辫、短发和卷发并存。

**导航**：见知识入口的历史发式速查。条目覆盖主要类型和常用古称，不是所有地区、族群、年代别名的穷尽目录；库外合理造型仍可提出，不虚构ID。

## CH-61 社会背景、年龄与活动的关联
<a id="ch-61"></a>

检索词：社会地位,平民,贵族,世家小姐,公主,皇后,男性,年龄,婚姻,场合
关联：CH-06,CH-16,CH-59
来源：S62,S66,S75,S76
证据：P,C,M

**关联**：平民劳作可优先紧凑少碍事的束髻，富裕或宫廷盛装可考虑较高/较宽髻与更复杂饰物；同一人物居家、宴饮、婚礼和礼仪可不同。世家小姐是创作背景，不直接等于某种法定品级；公主、皇后也不固定每天礼冠。

**宽松应用**：年龄、婚姻、家境、地域、族群与个人选择一起参与；材料实例支持的是关联，不给整个人群统计比例。清末民初发辫与剪发有城乡和时期差异。用户指定优先，建议不变成身份审查。

## CH-62 发式、冠帽、发罩与成品表达
<a id="ch-62"></a>

检索词：冠帽,发罩,发饰,发髻,名称,外形,表达,复原,历史发式
关联：CH-17,CH-18,CH-59
来源：S66,S67,S70,S78
证据：P,C,M

**组织**：发髻是头发结构，幞头/冠冕是首服，䯼髻是发罩，大拉翅是架饰，钿子是头饰；选择后检查底座、插戴和可见范围。帽内不可见头发不虚写细节。

**编译**：名称足够时保留名称；生僻古称或需要区分外形时，加一两处选定的轮廓/位置/固定特征。代表时代与适用人群留作设计依据，不全译入Prompt。正文级资料只支持其范围，摘要级作线索，造型组合为C、模型执行为M；不以专业术语保证成图。
