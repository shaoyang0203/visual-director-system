# 服装：秦汉至现代的选型基础

以中国服饰演变为主，现代兼顾已进入日常穿着的西式与功能服装。代表时期、人物关联和场合是设计线索；不做严格年代阶层配对。明确用户要求优先。正文依据、作者搭配建议和模型执行边界分开：C为本库工作设计，M表示未出图验证。

## CH-113 服装选型：时代、人物与活动
<a id="ch-113"></a>

检索词：服装知识,服饰,秦汉到现代,时代关联,社会地位,服装搭配
关联：CH-114,CH-115,CH-116
来源：S79,S97,S15
证据：P,C,M

**选型与组织**：先保留已定服装，再用时代氛围、地域传统、人物背景、当前活动、场合与气候挑选开放项。时期和身份是候选线索，不建立“某阶层只能穿某衣”的配对。平民可以整洁盛装，富裕人物可以穿便装；不从衣服推出品德、财富数值或新剧情。

**使用与表达**：朝代未定的古风可直接给合理方向；明确某时代时优先相应候选，跨时代幻想照用户意图完成。只有明确具体文物、某年典礼、准确复原或主动询问史实时，再核特定资料。

## CH-114 形制、套装、纹样与风格标签分开
<a id="ch-114"></a>

检索词：服装形制,服装名称,套装,纹样,飞鱼服,旗袍,新中式
关联：CH-113,CH-115,CH-116
来源：S79,S87,S109
证据：P,C,M

**选型与组织**：曲裾、圆领袍、褙子等帮助选择结构；袄裙和西装套装是组合；飞鱼纹或补子是纹样/身份符号；新中式是宽泛风格。名称可以关联但不能直接互换，不把纹样当领型，不把多个变体同时画在一件衣上。今人通称可用于检索，不冒充历史唯一原名。

**使用与表达**：名称足够时用名称；生僻或易混时补一两处已选定结构。库外款式可提出，不虚造KB。条目工作轮廓不是裁剪样板，时代与人物说明留作选型，不全塞入Prompt。

## CH-115 穿着层次、固定与活动余量
<a id="ch-115"></a>

检索词：衣层,内外搭,领襟,腰带,系带,季节,服装结构,衣摆
关联：CH-113,CH-114,CH-116
来源：S93,S103,S105,S15
证据：P,C,M

**选型与组织**：按内层、主衣、外搭和配件组织本图实际穿着。领襟、袖口、裙腰、开衩和系带各有归属；宽窄和厚薄随材质、动作与季节协调。坐姿、抬臂、骑乘与手持衣摆会改变褶和遮挡，不能仅凭服装名字假定动作成立。

**使用与表达**：只描写镜头能展示的层次；不把晚清衬衣译成现代shirt，不把氅衣高开裾画成裸露腿部；近景无需列鞋底纹。与既有CH-07~12及材质领域合用，不新增母版区域。

## CH-116 服装与妆发、状态及编译协同
<a id="ch-116"></a>

检索词：服装妆发,完整造型,头饰,妆造,编译,服装变化,现代
关联：CH-113,CH-114,CH-115
来源：S15,S97,S101
证据：P,C,M

**选型与组织**：服装、发型、妆容和冠饰围绕同一人物与当前活动协调；地位和服装不自动指定鼻型眉形。现代休闲与正式造型、古代家居与礼仪可以变化；同人物换场合不自动改体型、剪发、换脸或削弱用户明确要求。风雨、汗与磨损有活动依据才加入。

**使用与表达**：母版记本图选中的衣件、颜色材质、层次和必要识别点；编译保留已确认事实，不输出整个服装知识解释或自动叠加全部变体。修改已定服装沿用原改版与确认流程。资料支持限范围，搭配为C，图像执行为M/untested。
