# 构图知识库：横竖屏怎么选、人和东西摆哪最好看

> **调用铁律**：构图的本质是**先分清「看人为主」还是「看人景意境为主」**，再决定**配什么宽高比、把人和景物摆在什么位置**。
> 成稿时**不要往提示词里塞“三分法构图、对角线构图、中心构图”等生硬术语，也严禁把“占据主体、铺满宽横屏”等幕后说明词抄进正文**——直接用自然人话写清景别（如腰上半身、膝上七分身、全身入镜）、人物姿态或人景左右上下位置关系，并在代码块外给出配套宽高比。

---

## 一、核心分水岭：竖屏看人与横屏看意境，摆法完全不同！

1. **竖屏主打单人人像 / 角色写真（配 `9:16`、`2:3` 或 `3:4`）——人物就该居中占满主体！**
   - **什么时候用**：画面核心就是展现人物本身（颜值妆发、穿搭身材、眼神互动、手持道具拍照）。
   - **怎么摆最好看**：选择与动作匹配的景别（腰上半身不写腿脚，想展现叠腿或短裙腿线则选膝上七分身或全身），让人物自然居于竖屏中央（绝不往窄竖屏边缘乱挤导致切肩切手）！靠**鲜活的不对称姿态与身体曲线**打破呆板——例如重心压一侧腿微微顶胯、单手扶栏杆微侧身、抬手轻撩发丝或举小道具俏皮互动、微歪头直视镜头，背景用虚化的海面波光、摩天轮夜色光斑或霓虹灯管做干净衬底。

2. **横屏主打人景意境 / 叙事氛围（配 `16:9`、`21:9` 或 `3:2`）——别把人傻戳在横屏正中间！**
   - **什么时候用**：画面靠人物与广阔环境共同营造故事或意境（如宫墙落花、塞外送别、海滩独行、深夜酒馆发呆）。
   - **怎么摆最好看**：在宽横屏里把小人直挺挺戳正中间会把背景切碎成呆板游客照。此时应把人物放到**偏左或偏右区域**，让另一侧交给呼应景物或大片留空。

## 二、五种环境与动态摆位法（按题材选用）

### 1. 边缘人物 + 对侧景物遥望（宫墙式横屏摆位｜配 `16:9` 或 `21:9`）
- **怎么摆**：用一整面舒展背景托底（整面朱红宫墙、连绵远山、雾色湖面），人物放在画面**左侧或右侧边缘区域**，**对侧放一株斜探入画的老树树冠、一盏孤灯或停驻车马**；人物抬头或转头望向对侧景物，中间大片红墙或空气承接飘落花瓣与视线。
- **适用情况**：古典宫墙赏花、塞外离别、水岸孤舟等富有东方余味的横屏画面。

### 2. 下人上景 · 天地纵向呼应（仰望式竖屏摆位｜配 `3:4`、`2:3` 或 `9:16`）
- **怎么摆**：同样是竖屏，当重点不在近看五官穿搭，而在“地上的人与天上的景”（如拜月望云、沙丘顶望落雁、古树高门下仰望），把人物缩小放在**画面下三分之一处**抬头仰望，把**上方三分之二空间**留给满月薄云、斜落雁群或繁茂花冠。
- **适用情况**：闭月、落雁、高阁飞瀑、巨门古树下的纵向意境画面。

### 3. 运动与视线的“前方留空”（行进舒展摆位｜配 `3:2` 或 `16:9`）
- **怎么摆**：人物奔跑、跨水洼、骑行或侧脸远眺时，人物靠后一侧，**面朝和奔跑前进的前方留出更宽敞的街道或旷野**；平视舒展全身入镜（头顶留天、脚下留地，衣裤鞋履齐全，绝不贴地斜拍切掉人头）。
- **适用情况**：雨街奔跑抓拍、海边慢跑、骑马行进等动态题材。

### 4. 一侧偏居 · 大片净空放大情绪（留白式摆位｜配 `16:9`、`3:2` 或 `21:9`）
- **怎么摆**：表现孤独、走神或空寂时，人物偏居一侧，把另外大半幅画面干净留给阴云海面、空酒凳、雨窗或白雪。
- **适用情况**：阴雨海滩、深夜小酒馆独坐、晨雾溪畔、雪站台。

### 5. 巨景藏小人 · 悬殊尺度奇观（奇观式摆位｜配 `21:9`、`16:9` 或 `9:16`）
- **怎么摆**：让巨型沙丘、滔天巨浪、雪原或高墙铺满九成画面，把微小清晰的人物点在沙脊或墙脚一隅，用悬殊体量差制造震撼。
- **适用情况**：大漠孤影、纯视觉奇观、苍茫史诗大景。

## 三、宽高比推荐速决表

- **`9:16` / `2:3` / `3:4`（竖屏）**：① 单人颜值穿搭/身材写真（人物居中占满主体，靠姿态曲线出彩）；② 下人上景纵向仰望（望月、望雁、高树高墙）。
- **`16:9`（宽横屏）**：宫墙左右人景遥望、塞外荒原、电影感环境叙事。
- **`21:9`（超宽屏）**：极致辽阔大漠海岸、巨景藏小人、超长横向留空。
- **`3:2`（经典横屏）**：街头奔跑抓拍、酒馆茶室室内叙事、松弛日常纪实。
- **`1:1`（方屏）**：局部亲密特写、桌面静物、端正对称小品。
